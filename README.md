## Deskripsi
Ruangan Interior 3d menggunakan Three.js dengan 5 objek yang berbeda beda. setiap object bisa di klik untuk melihat informasi dan memberikan visual feedback saat di hover.

## Objeck dalam Scene
|objek | Geometri | warna |
|-------|----------|-------|
| meja | boxgeometry | coklat kayu |
| lampu | shperegeometry | kuning |
| gelas | cylindergeometry | biru muda |
| cincin | torusgeometry | emas |
| topi | conegeometry | merah |

## Fitur
1. 5 objek 3d dengan geometri berbeda
2. lighting : AmbienLight + DirectionalLIght dengan shadow
3. OrbitControl untuk memutar, zoom, dan pan kamera
4. animasi : lampu naik turun, cincin dan gelas berputar
5. Raycasting: hover feedback dan klik untuk lihat nama objectnya
6. webXR: tombol masuk mode VR
